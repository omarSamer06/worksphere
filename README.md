# HR Management System (MERN)

## 🚀 Overview

A modular HR management system built with the MERN stack.
This project focuses on employee management and leave approval workflows.

## 🛠️ Tech Stack

* React + Tailwind CSS
* Node.js + Express
* MongoDB + Mongoose
* JWT Authentication

## 📦 Features (Phase 1)

* Project setup and architecture

## 🔗 Deployment

* Backend: Render
* Database: MongoDB Atlas
